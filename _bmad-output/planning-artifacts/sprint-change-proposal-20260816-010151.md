# 스프린트 변경 제안 — HV-14 운영 경로 확정

승인 일시: 2026-08-16 01:01 +09:00  
승인자: Noah Lee  
변경 범위: Minor / 기존 계획 안의 직접 조정

## 1. 문제 요약

Story 7.3의 EOS 700D 실장비 비교에서 `embedded-jpeg`, `paired-jpeg`, `windows-shell-thumbnail` 세 빠른 소스 후보가 35회 촬영, 105개 판정에서 모두 0건 승인됐다. 따라서 후보를 제품 경로로 승격할 근거가 없으며, Story 7.4 이후가 사용할 명시적 대체 경로 결정이 필요했다.

## 2. 영향 분석

- Epic 7의 범위와 순서는 바뀌지 않는다.
- PRD의 darktable 기반 정확 경로와 충돌하지 않는다.
- 아키텍처는 이미 `raw-original`과 고정된 darktable 렌더러를 정확 경로로 지원한다.
- 고객 화면과 UX 흐름은 바뀌지 않는다.
- 빠른 JPEG 후보는 기본 비활성 상태를 유지한다.
- Story 7.4의 HV-15는 경로 결정 외의 품질 및 증거 조건을 별도로 충족해야 한다.

## 3. 승인된 방향

직접 조정을 채택한다.

- HV-14 후보 기술 판정: `Technology No-Go`
- 승인 운영 경로: `raw-original + pinned darktable 5.4.1`
- 근거: RAW 원본과 촬영 시점 프리셋을 같은 기준 렌더러로 처리하는 정확 경로이며, 현재 실장비에서 후보 JPEG 경로보다 안전하다.
- 일정 영향: 새 Epic이나 Story를 추가하지 않는다. Story 7.4의 선행 경로 결정만 해제한다.
- 위험: 속도는 느릴 수 있으며 Story 7.5~7.6에서 별도로 개선한다. 현재 촬영 결과의 심한 어두움은 이 결정으로 승인되지 않는다.

## 4. 상세 변경

### Story 7.3

이전: HV-14 `No-Go`, 승인된 운영 경로 없음, Story 상태 `review`.

변경: 세 빠른 소스 후보는 기술 `No-Go`로 유지하고 `raw-original + darktable`을 승인 대체 경로로 기록하여 조사 Story를 닫는다.

### Story 7.4 / HV-15

이전: HV-14 경로 결정이 선행 차단 요인.

변경: 경로 차단은 해제한다. 남은 차단 요인은 환경 확인 정보와 현재 사진 품질 판정이다.

### PRD / UX

변경 없음. 고객에게 편집 도구나 darktable 용어를 노출하지 않는 기존 제품 계약을 유지한다.

## 5. 인계와 완료 조건

- 개발/QA: `raw-original + darktable` 경로를 기준으로 HV-15 남은 증거를 정리한다.
- 제품 책임자: 현재의 매우 어두운 결과를 허용할지, 밝기를 고쳐 다시 촬영할지 결정한다.
- 성공 조건: HV-14 후보는 계속 비활성이고, Story 7.4는 HV-15의 남은 조건을 충족하기 전 `Go` 또는 `done`으로 기록하지 않는다.
