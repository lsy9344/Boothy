# Release Baseline — moved

The canonical Windows release baseline is **[`docs/release-baseline.md`](./docs/release-baseline.md)**.

This file used to hold a second copy that had drifted out of sync with reality: it claimed a CI
identity check that the workflow did not perform, and a `createUpdaterArtifacts: false` guardrail that
the configuration did not state. Both are now true, and both are described in one place.

This pointer stays because links to it may exist. It is not deleted quietly, and it never carries
content of its own again.
