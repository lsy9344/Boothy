# HV-17B 전환 탐지 검사

**선호 검사가 아니라 탐지 검사다.**

Story 7.4/7.5의 blind review는 "이 룩이 맞는가"를 묻는 **선호 검사**였다.
여기서 물어야 하는 것은 정반대다 — **"교체가 안 보였는가"**.

## 형식 (2026-08-16 Noah Lee 승인)

- 관찰자 **3명 × 20 시행**
- 그중 **10회는 실제 교체, 10회는 교체 없는 대조군**이며 **순서는 무작위**
- 관찰자는 교체가 일어나는지, 언제인지 **모른 채** 변화를 느낀 시점을 보고한다
- **통과 기준: 교체 시행의 탐지율 ≤ 대조군 오탐율 + 10%p**
- **최종 승인자: Noah Lee**

**5명 × 30 시행(150회) 형식은 쓰지 않는다.** 탐지 검사에 그 규모는 불필요하고,
Story 7.5가 패널 미확정으로 AC를 닫지 못한 이유가 규모였다.

## 대조군이 없으면 숫자가 아니다

대조군 없이 얻은 "아무도 못 봤다"는 결과는 **통과로 적지 않는다.**
무엇과 비교했는지가 없으면 그것은 관찰이지 측정이 아니다.
`check-raw-refined-evidence.ps1`이 대조군 부재를 기계적으로 차단한다.

## 진행 절차

1. 대조군 시행에서는 정밀본을 게시하지 않는다 (`BOOTHY_RAW_REFINED_MODE=off`로 그 시행만 돌리거나,
   같은 촬영을 proxy만으로 끝낸다). **관찰자에게 그 사실을 알리지 않는다.**
2. 교체 시행과 대조군 시행의 순서를 미리 무작위로 정하고 `trials.csv`의 `condition`에 기록한다.
   순서표는 진행자만 본다.
3. 관찰자는 관람 화면만 본다. 진행자의 표정·조작·소리로 단서를 주지 않는다.
4. 관찰자가 "사진이 바뀐 것 같다"고 느낀 시점에 보고한다. 보고가 없으면 `reportedChange=false`.
5. 세 관찰자의 실명과 Noah Lee 서명을 `signoff.md`에 남긴다.

## `trials.csv`

| 열 | 값 |
| --- | --- |
| `observer` | `observer-1` / `observer-2` / `observer-3` |
| `trial` | 1..20 |
| `condition` | `swap` (10회) 또는 `control` (10회) |
| `reportedChange` | `true` / `false` |
| `reportedAtMicros` | 변화를 느꼈다고 보고한 host monotonic 시각 (선택) |
| `note` | 자유 기술 (선택) |

`trials-template.csv`를 복사해 채운다. **시행을 빼지 않는다** — 관찰자가 자리를 비웠거나
장비 문제로 무효가 된 시행은 지우지 않고 `note`에 사유를 적고 그 회차 전체를 다시 돈다.
남은 시행만으로 비율을 내면 분모가 조용히 줄어든다.
