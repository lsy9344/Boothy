# Actual monitor frame evidence

정적 Windows Graphics Capture는 다음 파일에 보존했다.

- `visible-standby/viewer-after-capture.png`
- `hidden-prewarm/viewer-pre-capture-hidden.png`
- `hidden-prewarm/viewer-after-first-capture-foreground.png`

두 변형 모두 승인 고객 모니터에서 sample B의 최종 표시를 확인했다. hidden-prewarm은 촬영 전 viewer 창이 hidden 상태였고 첫 generation에서 공개됐다.

다만 120fps 이상 외부 촬영 rig가 없어 compositor-to-photon 오프셋과 A→B 전환 중 blank, stale image, crop/scale jump를 프레임 단위로 판정할 수 없다. 따라서 이 정적 캡처는 AC 3/5의 qualifying physical-frame evidence가 아니다.
