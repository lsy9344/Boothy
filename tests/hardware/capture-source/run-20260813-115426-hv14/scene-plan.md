# HV-14 Scene Plan

한 개의 새 세션에서 아래 순서로 셔터를 정확히 35회 누른다. 각 셔터는 세 비교 경로를 모두 생성하므로 별도로 105회 촬영하지 않는다.

| 셔터 번호 | 구분 | 장면 | 횟수 |
| --- | --- | --- | ---: |
| 1–5 | warm-up | 현재 부스의 일반 실내 장면 | 5 |
| 6–13 | measured | 밝고 균일한 장면 | 8 |
| 14–21 | measured | 어두운 장면 | 8 |
| 22–28 | measured | 사람/피부톤 장면 | 7 |
| 29–35 | measured | 밝은 영역과 어두운 영역이 함께 있는 고대비 장면 | 7 |
| **합계** |  |  | **35** |

## 고정 조건

- 현재 제품에서 쓰는 초점거리를 유지하고 회차 중 줌을 변경하지 않는다.
- 카메라/삼각대 위치와 구도를 고정한다.
- 화이트밸런스는 현재 부스의 고정 Kelvin 또는 고정 preset을 사용하고 AWB는 피한다.
- 각 장면 블록 시작 시 초점을 맞춘 뒤 가능하면 MF로 고정한다. 사람이 움직여 재초점하면 해당 사실을 기록한다.
- 각 장면 블록에서는 Manual 노출을 고정한다. 장면 전환 시에만 셔터속도·조리개·ISO를 조정한다.
- 연속촬영과 플래시는 사용하지 않는다. 현재 제품이 플래시를 사용하는 경우에는 35회 전체에 동일하게 적용한다.
- 카메라의 기존 RAW 설정을 운영자가 미리 바꾸지 않는다. 측정 lane이 필요한 값을 탐지·변경·복원한다.
